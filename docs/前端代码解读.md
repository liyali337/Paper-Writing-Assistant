# 前端代码解读

对应实现：`frontend/` 下的 React + Vite SPA。产品形态对齐 `docs/论文理解-技术方案.md` 附录 B，交互参考 ChatPDF：**左侧原文、右侧讲解、页码可跳转**。本期不做对话框问答。

开发地址：`http://localhost:5173/`（`npm run dev:web`）。`/api` 由 Vite 反代到 FastAPI `127.0.0.1:8000`。

### 1.1 没有新下载的包

这一轮**没有执行 `npm install`，也没有新增第三方 UI / PDF 库**。

`frontend/package.json` 里的依赖是 M0 骨架阶段就已经装好的，本轮只复用：

## 3. 页面状态机

`App.tsx` 只有一种会话：

```ts
type Session =
  | { kind: "landing" }
  | { kind: "workspace"; file: File | null; preview: boolean };
```

```text
Landing
  │ 选中 PDF  → workspace, file=PDF, preview=false   （立刻出分栏，左侧用本地 blob）
  │ 点「界面预览」→ workspace, file=null, preview=true （假论文 + 假讲解）
  ▼
Workspace
  │ 「换一篇」→ 回到 Landing
  │ 上传 501 时点「查看讲解界面预览」
  │          → 同一 file，preview=true（左真实 PDF，右演示讲解）
```

`Workspace` 的 `key` 是 `"preview" | "live"`，从 live 切到 preview 会整页重挂，用 `demo.ts` 填讲解，避免旧 state 残留。

## 4. 各文件在干什么

### 4.1 `api/types.ts`

把后端 Pydantic 模型抄成前端类型，避免 UI 自己发明字段：

- `Paper`：解析状态、`intro_status` / `method_status`、图数量
- `Section`：标题、kind、页码、`figure_ids`
- `Figure`：题注、页码、`storage_key`
- `PaperIntro` / `MethodExplain` / `MethodStep` / `Evidence`

另有 `HttpError`，带 `status` 和 FastAPI `detail`（`code` / `stage` / `message`）。

### 4.2 `api/client.ts`

所有请求走 `fetch('/api' + path)`。约定：

| HTTP | 行为 |
|---|---|
| 202 | 讲解未就绪，抛 `HttpError(202)`，轮询里当成 pending |
| 4xx/5xx | 读 `detail.message`，例如 M1 的 501 |
| 2xx | `JSON` 原样返回 |

导出：`uploadPaper`、`getPaper`、`getSections`、`getFigures`、`getIntro`、`getMethod`、`refreshIntro`、`refreshMethod`、`figureUrl`。图片不走 JSON，用 `<img src="/api/papers/{id}/figures/{fid}">`。

### 4.3 `Landing.tsx`

全屏首页。只负责选文件，**不在这里等上传结果**——选中立刻 `onPicked(file)`，让 Workspace 先打开 PDF（ChatPDF：文件一丢就能看）。

校验：扩展名 `.pdf`。拖拽和点击共用同一个 `handleFile`。

### 4.4 `Workspace.tsx`（核心）

阅读页状态都在这里：

1. **本地 PDF**：`URL.createObjectURL(file)`，卸载时 `revoke`。后端还没 ingest 完，左边已经能翻页。
2. **上传**：`preview===false` 时 `POST /papers`。成功记下 `paper_id`；501 则 `notice`，并提供切到预览。
3. **轮询**：有 `paper_id` 后约 1.6s 拉一次 `GET /papers/{id}`。`ready` 再拉 sections/figures；`intro_status` / `method_status` 为 ready 或 partial 再拉讲解。终态或 501 停止。
4. **分栏**：CSS 变量 `--analysis` 默认 42%，拖中间竖条 32%–58%。目录可用顶栏按钮收起（`--outline: 0`）。
5. **跳页**：目录、阅读顺序、`p.N` 徽章都调用 `jump(page)`，再交给 `PdfPane`。
6. **刷新**：当前 Tab 调 `POST ...?refresh=true`（不重裁图，与方案一致）。

顶栏芯片：解析中 / 已分解·N 图 / 介绍就绪 / 方法部分 / 需要文本型 PDF 等。

### 4.5 `PdfPane.tsx`

- 有 `pdfUrl`：`<iframe src="{blob}#page={n}&toolbar=0">`。`key={page}` 是为了让浏览器 PDF 插件吃到新页码（只改 hash 经常不跳）。
- 无 `pdfUrl`（纯预览）：用章节文本排成「纸张」稿，`scrollIntoView` 到 `data-page`。

翻页条上一页 / 输入页码 / 下一页，页数来自 `paper.page_count` 或章节 `page_end`。

### 4.6 `Outline.tsx`

按 `sections` 列出标题、`p.start–end`、图数量。`level > 1` 缩进。当前页落在该节区间则高亮。点击只跳页，不单独请求该节正文。

### 4.7 `IntroPanel.tsx` / `MethodPanel.tsx`

介绍：中文标题、一句话、问题/动机/贡献、任务设定、建议阅读顺序（点标题跳节）、总览图、折叠的原文摘录。

方法：总览 → 未被步骤引用的图（方案要求「未挂步骤的图跟在总览后」）→ 流水线步骤 → 关键模块 → 相对旧方案 → 假设 → 建议对照原文。每步有 `p.N`、章节名、可选摘录、步骤内插图。`partial` 时出警告条。

摘录默认折叠（方案缺省：先读中文）。

### 4.8 `FigureViews.tsx` / `DemoDiagram.tsx`

- 预览或 `storage_key === "demo"`：画 SVG（overview / pipeline 两张）。
- 真实论文：请求 PNG 字节。
- 点击进 `Lightbox`（Esc / 点遮罩关闭）。

### 4.9 `data/demo.ts`

一篇虚构的 *HieraAlign* 结构：6 个 section、2 个 figure、完整 intro/method。只为把布局填满，**不是真实论文，也不调用 LLM**。

### 4.10 `index.css`

设计 token：灰底 `#f3f5f7`、青绿强调 `#0f766e`、无渐变营销背景。落地页居中拖放；工作区 `grid` 四列（目录 / PDF / 拖条 / 讲解）。`<960px` 改成上下堆叠，隐藏目录和拖条。

## 5. 和后端怎么接

```text
选 PDF
  → 本地 blob 立刻进 iframe
  → POST /papers  multipart field=file
  → 轮询 GET /papers/{id}
        status=ready → GET .../sections 、 GET .../figures
        intro_status=ready|partial → GET .../intro
        method_status=ready|partial → GET .../method
  → 用户点刷新 → POST .../intro?refresh=true 或 .../method?refresh=true
  → <img> GET .../figures/{fid}
```

当前 FastAPI 这些路由仍返回 **501 not_implemented**（M1/M2 未落地）。因此：

- 上传后左侧 PDF 可用，右侧出现说明条 +「查看讲解界面预览」。
- 纯预览不打 API，只读 `demo.ts`。

`GET /health` 本轮 UI 没有再展示（旧顶栏有「后端 ok」），需要时可加回芯片。

## 6. 和 ChatPDF / 方案文档的差异

| 点 | ChatPDF | 本仓库这一期 |
|---|---|---|
| 右侧 | 自由问答 | 总体介绍 + 方法详解两个 Tab |
| 引用 | 对话里的 [n] | `p.N` 徽章跳 PDF 页 |
| PDF | 自研渲染 + 高亮 | 浏览器 iframe，无框选高亮 |
| 冷启动 | 只能上传 | 额外提供界面预览（后端未通时） |

相对方案附录 B 的「左章节树、中 Tab」：本轮把原文提到视觉中心（更像 ChatPDF），章节树收成窄目录；Tab 仍在右侧。

## 7. 怎么看、怎么验

```bash
# 终端 1
npm run dev:web

# 终端 2（可选，上传才会打到 API）
npm run dev:api
```

浏览器打开 `http://localhost:5173/`：

1. 点「查看完整界面预览」→ 应看到目录、假 PDF 纸张、中文介绍；切「方法详解」应有步骤和图；点 `p.3` 左侧应滚到第 3 页。
2. 拖入本地 PDF → 左侧应出现该文件；此时后端若 501，右侧提示可加载预览讲解。
3. M1/M2 接通后，同一套 `client.ts` 会换成真实章节与裁图，无需再加库。

类型检查（在仓库根或指定工程）：

```bash
node frontend/node_modules/typescript/bin/tsc --noEmit -p frontend/tsconfig.json
```
